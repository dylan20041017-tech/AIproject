# Git 提交信息规范

## 语言要求
- 所有 Git 提交信息必须使用中文
- 代码注释也使用中文

## 提交信息格式
```
<类型>(<模块>): <简短描述>

<详细描述>
```

## 类型说明
- feat: 新功能
- fix: 修复问题
- docs: 文档更新
- style: 代码格式调整
- refactor: 重构
- perf: 性能优化
- test: 测试相关
- chore: 构建/工具相关

## 示例
```
feat(用户模块): 添加用户登录功能

1. 添加登录表单验证
2. 添加登录接口调用
3. 添加登录状态管理
```
